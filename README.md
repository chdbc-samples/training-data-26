# Приклад виконання практичної роботи №3 «Робота з Map в Java» з дисципліни "Програмування мовою Java"

## Завдання

```text
Назва record-класу рослини: Oak (дуб)
Характеристики рослини: вид (String species), вік, років (Integer age)

Сортування:
- вид - за зростанням
- вік - за спаданням

Map<рослина, місце зростання>:
  Oak{species='Дуб звичайний', age=250} -> Софіївка
  Oak{species='Дуб червоний', age=80} -> Голосіївський парк
  Oak{species='Дуб скельний', age=120} -> Холодний Яр
  Oak{species='Дуб звичайний', age=1000} -> Холодний Яр
  Oak{species='Дуб пухнастий', age=60} -> Ботанічний сад імені Фоміна
  Oak{species='Дуб болотяний', age=45} -> Софіївка
  Oak{species='Дуб червоний', age=35} -> Ботанічний сад імені Фоміна
  Oak{species='Дуб австрійський', age=90} -> Олександрія
  Oak{species='Дуб звичайний', age=500} -> Олександрія
  Oak{species='Дуб скельний', age=300} -> Тростянець

Ключ/значення для додавання: Oak{species='Дуб монгольський', age=70} -> Тростянець
Ключ для пошуку і видалення: Oak{species='Дуб скельний', age=120}
Значення для пошуку і видалення: Софіївка
Порівняти продуктивність: HashMap з TreeMap
```

## Як запустити

Скомпілювати й виконати з кореня репозиторію (Windows PowerShell 7):

```powershell
chcp 65001
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

java .\BasicDataOperationsUsingMap.java
```
